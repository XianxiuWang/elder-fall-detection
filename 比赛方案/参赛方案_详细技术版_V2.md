### 创新点一：从"事后识别"到"事前预判"的范式转变

#### 2.1.1 跌倒方向——步态退化趋势预测模型

**核心问题**：传统方案跌倒检测依赖摔倒瞬间的姿态突变（如TVT异常），是"发生了才报警"。我们需要在发生前几小时到几天就预测到风险。

**技术方案：基于双流时序Transformer的步态退化预测**

```
输入：15天连续步态参数序列
输�出：未来72小时内跌倒风险概率

架构：
┌──────────────────────────────────────┐
│  步态参数（每日聚合）                  │
│  [步速, 步幅, 步频, 对称性, 双足支撑, │
│   转身时间, 站立晃动, 扶墙频次]       │
│         ↓                            │
│  ┌─────────┐   ┌─────────┐          │
│  │ 短程流   │   │ 长程流   │          │
│  │ 7天窗口  │   │ 30天窗口 │          │
│  │ PatchTST │   │ PatchTST │          │
│  └────┬────┘   └────┬────┘          │
│       └──────┬──────┘               │
│              ↓                       │
│     Cross-Attention 融合              │
│              ↓                       │
│     MLP 风险概率头                     │
│     输出: P(72h跌倒) ∈ [0,1]         │
└──────────────────────────────────────┘
```

**技术创新细节：**
1. **双时间尺度**：短程流（7天滑动窗口）捕捉近期的快速退化（如急性疾病），长程流（30天窗口）捕捉慢性的渐进退化（如肌少症进展）
2. **PatchTST**：将步态时间序列分割为子序列patch，每个patch独立编码后再做跨patch注意力，比传统LSTM对长期依赖的建模更好，且计算效率更高
3. **早停信号设计**：当模型连续3天输出的风险概率递增且>0.5时，触发风险预警。这比事后检测平均提前了**3-7天**

**训练数据策略：**
- 公开数据集：URFD（跌倒检测）、CASIA-B（步态识别）用于预训练姿态估计
- 步态退化模拟：招募志愿者通过穿戴加重绑腿（模拟肌力下降）、单侧增高鞋（模拟步态不对称）来模拟退化过程
- 数据增强：时间扭曲、幅度缩放、随机掩码增强鲁棒性

#### 2.1.2 心理方向——行为节律偏离度分析模型

**核心问题**：心理状态评估传统上靠量表（GDS-15、MMSE等），主观性强且需要老人配合。我们要通过客观行为数据实现无感的连续评估。

**技术方案：基于余弦节律模型 + 多维偏离度指数（MDI）**

```
算法流程：

Step 1: 基线建模（前14天）
  对每个时间槽（每小时），统计：
  - 活动量的均值 μ_h 和标准差 σ_h
  - 形成一天24小时的"正常节律曲线"

Step 2: 每日偏离度计算
  MDI_day = α·D_activity + β·D_sleep + γ·D_social + δ·D_emotion

  其中：
  D_activity = Σ|obs_h - μ_h|/σ_h / 24  （活动偏离度）
  D_sleep   = |睡眠时长 - 基线睡眠|/基线睡眠 + |入睡偏移|/60min  （睡眠偏离度）
  D_social   = max(0, 基线社交频次 - 实际社交频次)/基线社交频次  （社交减少度）
  D_emotion  = Σ(负面表情占比 - 基线占比)  （情绪偏离度）

Step 3: 趋势分析（EWMA）
  EWMA_t = λ·MDI_t + (1-λ)·EWMA_{t-1},  λ=0.2

Step 4: 预警规则
  · EWMA连续7天 > 1.5σ → 黄色关注（可能进入亚健康状态）
  · EWMA连续14天 > 2σ → 橙色预警（建议心理评估）
  · EWMA连续21天 > 2σ + 社交接近0 → 红色告警（严重社交孤立风险）
```

**关键技术创新：**
- **无阈值设计**：不依赖人群通用阈值，基于个人基线做相对偏离，不同老人的"正常"范围完全不同
- **多模态联合**：单一维度变化不一定有问题（比如老人回老家社交减少但情绪更好），只有多维度同时恶化才触发预警
- **季节性自适应**：基线每30天自动更新一次（指数衰减加权），适应季节性变化和康复进展

#### 2.1.3 诈骗方向——实时多通道阻断引擎

**核心问题**：诈骗识别的关键不是"识别诈骗"，而是**在转账/泄密发生前阻断**。

**技术方案：流水线式实时检测 + 三级阻断策略**

```
电话通话中：
  音频流 → Whisper流式转写 → 敏�感词匹配(毫秒级) → BERT话术分类
                                            ↓
                                   任一命中 + 置信度>0.7
                                            ↓
                              ┌── 阻断策略决策 ──┐
                              │                   │
                     高风险(>0.9)          中风险(0.7-0.9)
                              │                   │
                      自动挂断+               萤石设备语音
                      家属即时电话              播报提醒老人
                              │                   │
                              └──────┬────────────┘
                                     ↓
                              家属App推送+通话记录标记
```

**三层阻断策略：**

| 层级 | 触发条件 | 阻断方式 | 延迟 |
|------|----------|----------|:----:|
| L1-预警 | 陌生号码+通话>5min | 萤石设备屏幕闪烁提示 | <1s |
| L2-警告 | 敏感词≥3个/话术置信度>0.7 | 萤石语音播报"请注意，通话可能涉及诈骗" | <2s |
| L3-阻断 | 紧急话术（转账/密码/验证码） | 1.通话自动挂断保护 + 2.App强制推送家属 + 3.如确认诈骗→联动社区 | <3s |

**诈骗话术训练数据构建：**
- 搜集公开诈骗录音+公安部公开案例→人工标注2000+条话术样本
- 数据增强：GPT辅助生成变体话术（同一诈骗套路的多种说法）
- 关键词库：建立5类诈骗关键词库（冒充公检法/投资理财/保健品/亲情/中奖）

### 创新点二：基于个人基线的动态风险评估

#### 2.2.1 个体基线建模

**核心思路**：不用群体统计阈值来评判单个老人，每个人的"正常"都不同。

```
个人数字画像（7个维度，每个维度建立μ和σ）：

        步态              活动              社交
    ┌─────────┐      ┌─────────┐      ┌─────────┐
    │·步速    │      │·活动时长│      │·通话频次│
    │·步幅    │      │·活动时段│      │·通话时长│
    │·对称性  │      │·活动强度│      │·访客频次│
    └────┬────┘      └────┬────┘      └────┬────┘
         │                │                │
         └────────┬───────┴────────┬───────┘
                  │                │
              ┌───┴────┐     ┌────┴───┐
              │  睡眠   │     │  情绪   │
              │·时长    │     │·正面表情│
              │·节律    │     │·负面表情│
              │·夜间活动│     │·语音情绪│
              └────────┘     └────────┘
```

**基线建立与更新机制：**

```
阶段1: 初始基线（第1-14天）
  收集所有维度数据 → 计算各维度的 μ_init 和 σ_init
  
阶段2: 稳定运行期（第15天起）
  每日计算各维度偏离度：
  z_score = (x_today - μ_baseline) / σ_baseline
  
阶段3: 自适应基线更新（每30天）
  μ_new = 0.85·μ_old + 0.15·μ_recent30  (EMA更新)
  σ_new = 0.85·σ_old + 0.15·σ_recent30
  
  目的：适应季节性变化（冬天活动少正常）、康复进展（手术后步速逐渐恢复）、
        但不被短期异常污染（诈骗周不出门不应拉低基线）
```

#### 2.2.2 跨维度联合风险评估

**关键技术：基于贝叶斯网络的联合风险推理**

```
贝叶斯网络结构（简化）：

        [生活环境变化] ──→ [步态异常]
                              ↓
        [睡眠质量下降] ──→ [活动量下降]
                              ↓
        [情绪持续低落] ──→ [社交行为减少]
                              ↓
        [认知功能变化] ──→ [异常交互行为] ←── [外部诈骗接触]
                              ↓
                         [综合风险等级]
```

**为什么用贝叶斯网络？**
- **可解释性**：可以追溯是哪条因果链触发了预警（"因为睡眠连续变差→活动量下降→情绪低落"）
- **先验知识融合**：可以将医学先验（如认知衰退→步态不稳定）编码进网络结构
- **不确定性处理**：当某些传感器数据缺失时，仍能基于已有证据给出置信区间

#### 2.3.2 模型轻量化方案

| 模型 | 原始大小 | 轻量化方案 | 轻量化后 | 精度损失 |
|------|:--------:|------------|:--------:|:--------:|
| MediaPipe Pose | 12MB | ONNX INT8量化 | 3.5MB | < 1% |
| YOLOv8-nano | 6.2MB | ONNX FP16 + 剪枝 | 2.1MB | < 2% |
| MobileFaceNet | 4.5MB | TensorRT INT8 | 1.8MB | < 1% |
| 跌倒检测CNN | 8MB | 知识蒸馏（Student tiny） | 1.2MB | < 3% |
| FunASR (Whisper-tiny) | 72MB | 云端运行，无需优化 | — | — |
| BERT诈骗分类 | 102MB | 云端运行 + 模型缓存 | — | — |

**边缘端总内存预算：约 15MB**，可在萤石适老化设备上流畅运行。

#### 2.3.3 隐私保护设计

```
数据分级处理：

本地（不离开设备）：
  ✅ 原始视频流 → 仅提取骨骼点坐标后丢弃原始帧
  ✅ 人脸特征向量 → 比对人脸后丢弃原始图像
  ✅ 原始音频 → 仅保存转写文本和分类结果

云端（脱敏后上传）：
  ✅ 骨骼点坐标序列（无法反推原始图像）
  ✅ 行为事件特征摘要（非原始视频）
  ✅ 转写文本（不含声纹特征）

家属端查看：
  ✅ 仅在预警时推送脱敏通知
  ✅ 异常事件经老人/家属双重授权后才可查看原始片段
```
