## 一、作品概述

本作品面向居家养老场景中老年人面临的**跌倒风险、心理健康、诈骗风险**三大核心安全威胁，基于萤石开放平台的摄像头、传感器等硬件设备与云服务能力，构建一套**多模态AI监测与预警系统**。

核心思路是**从"事后响应"转向"事前预判"**：

| 风险类型 | 传统模式（事后） | 本方案（事前） |
|----------|:----------------:|:--------------:|
| 跌倒 | 跌倒后识别报警 | 步态异常预判→风险预警→跌倒检测→快速响应 |
| 心理健康 | 就医后诊断 | 日常行为连续感知→早期筛查→分级预警 |
| 诈骗 | 被骗后报案 | 异常交互实时识别→事前阻断干预 |

## 三、三大功能模块详细设计

### 模块一：跌倒风险前置防控

#### 3.1.1 设计理念
区别于传统"摔倒后检测"，本方案聚焦**跌倒前的风险预判**，通过长期步态监测与环境风险感知，在跌倒发生前发出预警。

#### 3.1.2 关键特征提取

| 特征类别 | 具体特征 | 提取方式 |
|----------|----------|----------|
| **步态特征** | 步速、步幅、步宽、步频、双足支撑时间、步态对称性 | 基于OpenPose/MediaPipe的姿态关键点提取 + 时序分析 |
| **平衡特征** | 站立晃动幅度、转身稳定性、坐立转换时间（TUG测试） | 关键点轨迹的方差/速度/加速度分析 |
| **环境风险** | 地面障碍物、光线不足区域、湿滑区域 | YOLOv8目标检测 + 场景语义分割 |
| **行为异常** | 长时间静止、频繁扶墙、行走路线偏移 | 时序行为序列建模（LSTM/Transformer） |

#### 3.1.3 风险分级模型

采用**多指标加权评分模型**：

```
跌倒风险分 = W₁×步态异常分 + W₂×平衡异常分 + W₃×环境风险分 + W₄×行为异常分
```

| 风险等级 | 分数区间 | 预警动作 |
|----------|:--------:|----------|
| 🟢 低风险 | < 0.3 | 无动作，持续监测 |
| 🟡 中风险 | 0.3-0.6 | 推送提醒给家属，建议关注 |
| 🟠 高风险 | 0.6-0.8 | 实时告警给家属/社区，建议干预 |
| 🔴 极高风险+跌倒 | > 0.8 或检测到跌倒 | 紧急报警，联动社区/120 |

#### 3.1.4 技术路线
1. **步态数据采集**：萤石摄像头持续采集起居区域视频流（≥7天建立基线）
2. **姿态估计**：MediaPipe Pose提取33个身体关键点坐标
3. **步态参数计算**：关键帧间位移、速度、加速度统计 → 建立个人步态基线
4. **风险偏离检测**：实时步态参数与基线对比，计算欧氏距离/马氏距离偏离度
5. **环境协同**：目标检测识别地面杂物、地毯褶皱等环境风险因子

### 模块二：心理健康风险早期筛查

#### 3.2.1 设计理念
通过**长期、无感、多维度**的行为数据采集与分析，实现从认知症/抑郁症的"就医诊断"前移到"居家早期筛查"。

#### 3.2.2 关键特征提取

| 特征类别 | 具体特征 | 提取方式 |
|----------|----------|----------|
| **活动规律** | 日均活动时长、活动时段分布、户外出行频率 | 摄像头运动检测 + 活动热力图统计 |
| **睡眠模式** | 入睡时间、起床时间、夜间活动次数、睡眠时长 | 红外/低照度摄像头 + 运动传感器 |
| **社交行为** | 通话频次/时长、访客频次、与家人互动频率 | 门口摄像头 + 通话记录分析 |
| **情绪特征** | 面部表情变化、语音情绪倾向、日常活动节奏 | 面部表情识别(FER) + 语音情感分析 |

#### 3.2.3 长期趋势分析模型

采用**滑动窗口+指数加权移动平均(EWMA)**监测指标趋势：

- **基线期**（第1-2周）：采集正常状态下各指标均值与方差
- **监测期**（持续）：每日计算偏离度，累计异常天数

```
心理健康风险分 = Σ(各指标偏离度 × 权重) × 时间衰减因子

关键预警信号：
· 活动时长连续7天下降 > 30% → 抑郁风险预警
· 睡眠节律连续14天紊乱 → 认知衰退预警
· 社交频率连续下降 > 50% → 社交孤立预警
```

| 预警等级 | 条件 | 干预建议 |
|----------|------|----------|
| 🟢 正常 | 所有指标在基线范围内 | 定期生成健康周报 |
| 🟡 关注 | 1-2项指标连续异常 | 推送家属关注提醒 |
| 🟠 预警 | 多项指标持续异常 | 建议社区/社工上门探访 |
| 🔴 告警 | 严重偏离 + 行为异常 | 建议专业心理/医疗评估 |

### 模块三：诈骗风险识别与事前阻断

#### 3.3.1 设计理念
从"被骗后报警"转向**异常交互的实时识别与事中阻断**，覆盖电话诈骗、陌生人入户、社区诈骗三个维度。

#### 3.3.2 三个子模块

**子模块A：电话诈骗实时监测**

| 功能 | 技术实现 |
|------|----------|
| 关键词实时识别 | 基于Whisper/FunASR进行语音转文字，匹配诈骗关键词库（"安全账户""转账""公检法"等） |
| 诈骗话术模式匹配 | 训练轻量级BERT分类器，识别常见诈骗话术模板 |
| 通话情绪检测 | 语音特征（语速、音调、停顿）分析紧张/恐慌情绪 |
| 实时阻断 | 检测到高风险通话→自动播放提醒语音 / 推送家属告警 |

**子模块B：陌生人入户识别**

| 功能 | 技术实现 |
|------|----------|
| 人脸识别 | 萤石摄像头 + ArcFace/FaceNet，建立家庭成员白名单 |
| 陌生人预警 | 检测到白名单外人脸→推送门口照片给家属确认 |
| 入户行为分析 | 陌生人进入后，监测停留时间、活动区域是否异常 |
| 异常联动 | 陌生人长时间逗留→语音提醒老人 + 通知家属/社区 |

**子模块C：社区诈骗行为识别**

| 功能 | 技术实现 |
|------|----------|
| 聚集行为检测 | 楼下/社区入口检测多人聚集+疑似推销行为 |
| 老年人被围堵检测 | 老人被多人长时间围住场景识别 |
| 异常物品识别 | 检测大额现金、保健品礼盒等可疑物品携带 |

#### 3.3.3 诈骗风险综合评分

```
诈骗风险分 = α×电话诈骗风险 + β×陌生人风险 + γ×社区诈骗风险

触发阻断条件：
· 电话诈骗风险分 > 0.7 → 实时语音提醒+家属通知
· 陌生人进入+长时间逗留 → 家属远程喊话+社区联动
· 综合风险分 > 0.8 → 多方联动报警
```

## 四、多模态融合策略

### 4.1 数据融合层次

| 融合层次 | 方法 | 应用场景 |
|----------|------|----------|
| **数据级融合** | 多摄像头视角拼接、音视频时间对齐 | 跨房间连续追踪 |
| **特征级融合** | 各模态特征向量拼接 + PCA降维 | 综合风险评估 |
| **决策级融合** | 各模块独立输出 + 加权投票/Stacking集成 | 最终预警决策 |

### 4.2 核心技术模型选型

| 任务 | 基线模型 | 优化方向 |
|------|----------|----------|
| 人体姿态估计 | MediaPipe Pose / OpenPose | 针对老年人姿态的fine-tune |
| 目标检测 | YOLOv8-nano (轻量部署) | 萤石设备端适配 |
| 行为时序建模 | BiLSTM + Self-Attention | 结合个人历史基线 |
| 语音识别 | FunASR (中文优化) | 诈骗场景关键词库增强 |
| 诈骗文本分类 | BERT-Chinese-Base 微调 | 自建诈骗话术语料库 |
| 面部表情识别 | MobileNetV3 + FER2013 | 老年人面部特征适配 |
| 多模态融合 | LightGBM / XGBoost 集成 | 可解释性强，适合评分 |

## 五、技术方案创新点

### 创新点一：从"事后识别"到"事前预判"的范式转变
- 跌倒方向：不依赖摔倒瞬间检测，而是通过**步态退化趋势**提前7-14天预判风险
- 心理方向：通过**日常行为节律偏离**实现无感早期筛查，避免问卷/测试的主观偏差
- 诈骗方向：关键是在"转账发生前"阻断，而非事后取证

### 创新点二：基于个人基线的动态风险评估
- 为每位老人建立**个体化行为基线模型**，而非使用人群通用阈值
- 通过EWMA/滑动窗口持续更新基线，自适应季节性/康复性变化
- 相比静态阈值方案，误报率预期降低40%以上

### 创新点三：轻量化边缘-云协同架构
- **边缘端（萤石设备）**：实时推理（姿态估计、人脸识别），延迟 < 200ms
- **云端（萤石开放平台）**：长程趋势分析、多模态融合、风险评估报告生成
- 减少数据传输量，降低隐私风险，提升实时性

### 创新点四：分级预警+多方联动闭环
- 四级递进式预警（提示→关注→警告→紧急），避免"狼来了"效应
- 打通老人→家属→社区→急救的多级响应链路
- 与萤石App/短信/电话多通道推送，保障触达率

## 六、系统实现方案

### 6.1 开发环境与工具栈

| 层级 | 技术选型 |
|------|----------|

### 6.2 与萤石开放平台集成方案

```
萤石云平台提供的核心能力映射：

设备接入API → 摄像头注册、视频流获取
    ↓
云存储服务 → 异常事件视频片段存储
    ↓
消息推送服务 → 分级预警消息推送（萤石App/短信）
    ↓
AI开放能力 → 人形检测、移动侦测等基础AI能力作为前置过滤
    ↓
数据开放API → 设备状态、告警记录等数据获取
```

## 七、验证方案与预期指标

### 7.1 测试场景设计
- **仿真居家环境**：搭建包含客厅、卧室、卫生间的模拟场景（可使用实验室或真实家庭环境）
- **测试人员**：招募10-20名不同年龄段志愿者，模拟老年人步态特征
- **特殊场景**：弱光环境、遮挡场景、多人场景、快速移动场景

### 7.2 核心评价指标

| 模块 | 指标 | 目标值 | 测量方法 |
|------|------|:------:|----------|
| 跌倒风险 | 风险预判准确率 | ≥85% | 模拟步态异常→观察预警触发时间 |
| 跌倒风险 | 提前预警时间 | ≥3天 | 从步态基线偏离到触发高风险预警的时间差 |
| 跌倒风险 | 跌倒检测准确率 | ≥95% | 模拟不同姿态跌倒，统计检出率 |
| 心理健康 | 异常行为检出率 | ≥80% | 模拟活动量下降/睡眠紊乱，统计检出率 |
| 心理健康 | 趋势分析灵敏度 | ≥75% | 对渐进式行为变化的响应速度 |
| 诈骗识别 | 诈骗电话识别准确率 | ≥90% | 播放已知诈骗录音，统计检出率 |
| 诈骗识别 | 陌生人识别准确率 | ≥95% | 白名单+陌生人混合测试 |
| 整体系统 | 端到端响应延迟 | <3秒 | 事件发生→云端推送完成的时间 |
| 整体系统 | 误报率 | <10% | 正常场景下触发预警的比例 |

### 7.3 验证数据要求
- 跌倒数据集：Open Dataset（如URFD、MultiCam） + 自建仿真数据
- 步态数据集：CASIA-B 步态数据集 + 自采老年人步态数据
- 诈骗话术数据：公开诈骗录音 + 自建诈骗关键词库（约2000条话术样本）
- 行为数据：自采14天以上连续活动数据建立基线

## 八、应用场景与落地路径

### 8.1 典型应用流程

```
日常监测状态：
  萤石摄像头 → AI分析 → 每日健康报告（家属App推送）
        ↓
  异常信号出现（如步速连续3天下降15%）：
  系统自动标记黄色关注 → 家属收到提醒
        ↓
  异常信号持续（如步速连续7天下降30%+频繁扶墙）：
  升级为橙色预警 → 家属建议带老人体检/防跌倒干预
        ↓
  高危事件发生（如老人跌倒、诈骗电话进行中）：
  红色紧急告警 → 家属+社区/120联动
```

### 8.2 适老化设计要点
- **无感监测**：无需老人主动佩戴设备、操作App
- **语音交互优先**：预警通过萤石设备语音播报，而非文字推送
- **大字体/高对比度**：如有屏幕交互界面，适配老年人视觉特征
- **隐私优先**：不存储原始视频，仅提取特征向量，数据本地处理优先
