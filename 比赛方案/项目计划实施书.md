# AI 智能居家监护系统 —— 项目计划实施书

> **版本：** V2.2（新增主动预测 + 大模型交互，8 周开发计划，硬件：Orange Pi 5 Plus / RK3588）
> **核心定位：** 从"被动报警"升级为"主动预测"，从"冷冰冰的监控"升级为"有温度的陪伴"

---

## 一、项目背景与痛点分析

### 1.1 现状问题

中国 60 岁以上人口已超 2.8 亿，独居老人数量持续增长。现有养老监护产品普遍存在三大短板：

| 痛点 | 现状 | 本方案解法 |
|---|---|---|
| **只能事后报警** | 跌倒后通知家属，但伤害已经发生 | 通过步态分析提前 3-7 天预警跌倒风险 |
| **只管身体不管心理** | 只监测"摔没摔"，不关心"开不开心" | 情绪曲线追踪+社交活跃度画像，提前发现抑郁风险 |
| **没人味** | 冷冰冰的报警音、机械化的提醒 | LLM 驱动的自然对话，家人声音克隆，回忆疗法 |

### 1.2 核心创新点

```
┌─────────────────────────────────────────────┐
│  创新一：从"被动报警"→"主动预测"              │
│  ├── 跌倒风险预测（步态分析，提前 3-7 天预警）  │
│  ├── 情绪趋势追踪（长期心情曲线，异常预判）     │
│  └── 社交活跃度画像（社交隔离风险自动发现）     │
├─────────────────────────────────────────────┤
│  创新三：大模型赋能，"有人味"的 AI 陪伴        │
│  ├── AI 每日问候 + 无感认知评估（MMSE AI 版）   │
│  ├── 回忆疗法引擎（老照片/老歌驱动对话）        │
│  └── 家人声音克隆（用子女声音提醒+报警）       │
└─────────────────────────────────────────────┘
```

## 三、创新模块详细设计

### 创新一：主动预测引擎

#### 3.1.1 跌倒风险预测（步态分析）

**核心理念：** 不等跌倒发生，而是通过长期步态变化提前预警。

| 监测维度 | 具体指标 | 技术方案 |
|---|---|---|
| 步行速度 | 日常走动速度（cm/s）变化趋势 | MediaPipe 提取关节点 → 计算步态周期时间 |
| 步幅 | 步幅长度变化 | 左右踝关节距离，连续 7 天做趋势分析 |
| 身体晃动 | 躯干倾斜角度 + 晃动幅度 | 肩-髋连线与垂直方向夹角 |
| 步态对称性 | 左右腿步幅差异 | 左右踝位移量对比 |
| 转弯稳定性 | 转弯时身体倾斜程度 | 角速度 + 重心偏移 |

**算法流程：**

```
摄像头采集 → MediaPipe 提取 33 个骨骼关键点
    ↓
每帧计算：步长、步速、晃动角、对称性
    ↓
每日聚合：日均值 + 方差 + 最大偏差
    ↓
滑动窗口（7天）趋势分析 → 输出"跌倒风险评分"（0-100）
    ↓
评分持续上升 → 推送预警："王奶奶跌倒风险从 35 升至 68，建议关注"
```

**技术栈：** PyTorch（时序模型 LSTM/Transformer）+ MediaPipe（实时关节点）+ InfluxDB（长期时序存储）

#### 3.1.2 心理状态趋势追踪

**核心理念：** 不判断"此刻开心还是难过"，而是画出一条**情绪曲线**，关注长期趋势。

| 情绪源 | 采集方式 | 分析维度 |
|---|---|---|
| 面部表情 | CV 表情识别（7 分类：开心/难过/愤怒/惊讶/恐惧/厌恶/中性） | 每日情绪分布占比 |
| 语音情绪 | NLP 情感分析（通话/对话转写后的文本） | 正面/负面/中性比例 |
| 活动量 | 每日移动轨迹、出门次数 | 活跃度指数 |
| LLM 对话 | AI 问候中老人的回复语义分析 | 语言积极性评分 |

**输出：** 情绪健康指数看板

```
日期: 7/6   7/7   7/8   7/9   7/10  7/11  7/12
  积极 ████  ███   █     █     ██    ██    ███
  中性 ██    ██    ██    ██    ██    ██    ██
  ⚠️ 消极 ░░    ░░░░  ░░░░  ░░░░  ░░░   ░░    (连续低落 → 触发预警)
```

#### 3.1.3 社交活跃度画像

自动统计老人社交频率，发现社交隔离风险：

- **每日对话次数**（与家人通话 + AI 问候交互）
- **出门频次**（通过门口摄像头识别）
- **访客频率**（门口人脸识别统计）
- **社交活跃度评分** → 连续下降 7 天触发"社交隔离风险"预警

### 创新三：LLM 大模型赋能交互

#### 3.2.1 AI 每日问候 + 无感认知评估

**核心理念：** 把认知筛查量表（MMSE）"藏"进日常闲聊里，不刻意、不尴尬。

**对话示例：**

```
AI (家人声音): 王奶奶早啊，昨晚睡得好吗？
老人: 还行，就是三点多醒了一次。

AI: 今天外面 28 度，记得多喝水。
    对了，我上次说的那个电视剧，主角叫啥来着？
    ⬆️ (自然嵌入的"延迟回忆测试")

老人: 叫... 哎呀一下想不起来了...

AI: 没事没事，就是一个穿红衣服的姑娘嘛。
    中午想吃啥？我看看冰箱里还有啥...
    ⬆️ (自然转入下一个话题，不纠结)
```

**评估维度（对应 MMSE 简化版）：**

| 认知能力 | 嵌入方式 | 评估指标 |
|---|---|---|
| 定向力 | "今天星期几还记得吗？" | 日期/时间/地点正答率 |
| 记忆力 | 上一轮提到的话题是否记得 | 延迟回忆准确率 |
| 计算力 | "上次说买了 3 斤苹果 2 斤梨，一共几斤？" | 计算正确率 |
| 语言能力 | 对话中词汇丰富度、语法复杂度 | NLP 自动分析 |
| 视空间 | 通过摄像头识别物品摆放对不对 | 环境变化检测 |

**输出：** 每月生成一份"认知健康报告"，附带趋势曲线，早筛阿尔茨海默潜在风险。

#### 3.2.2 回忆疗法（Reminiscence Therapy）

**临床依据：** 回忆疗法被广泛验证对延缓阿尔茨海默症、改善老年抑郁有显著效果。

**功能设计：**

| 阶段 | 内容 | 实现方式 |
|---|---|---|
| **家属上传** | 老照片、老歌、老物件图片 | Web 前端 上传 + 语音描述 |
| **AI 拆解** | 自动提取照片中的人物、场景、年代 | CV 图片理解 + LLM 生成背景知识 |
| **AI 发起话题** | "王奶奶，这是你们厂 1968 年的合影吧？中间穿白衬衫的是您吗？" | LLM 基于家属提供的记忆素材生成个性化话题 |
| **对话引导** | 老人讲述 → AI 追问细节 → 记录回忆片段 | 记忆成为"数字回忆录"，子女可回看 |

**Web前端体验：** 手机 App 上可以看到"奶奶今天聊了 1968 年进厂的故事，她提到了张师傅、李主任，讲了 12 分钟，情绪很愉悦 😊"

#### 3.2.3 家人声音克隆

**核心理念：** 老人对"机器音"天然抵触，但如果是子女声音，接受度高得多。

**技术方案：**

| 环节 | 方案 |
|---|---|
| 声音采集 | Web 前端 录制 5 分钟朗读素材 |
| 声音训练 | 开源 TTS 模型（如 GPT-SoVITS）微调 |
| 触发场景 | 吃药提醒、异常告警、AI 日常问候、天气预报 |
| 隐私保障 | 声音模型仅存储在本地边缘设备，不上传云端 |

**效果对比：**

```
传统: 🔔 "哔——请按时服药"               → 老人: 烦死了，关了
升级: 👧 "爸，十点了，该吃那颗白色药片了"  → 老人: 哦好的好的
```

**技术栈：** GPT-SoVITS / CosyVoice（语音克隆）+ Whisper（语音识别）+ Llama/通义千问（对话大模型）

## 八、风险与应对

| 风险 | 等级 | 应对策略 |
|---|---|---|
| LLM 推理延迟过高 | 中 | 使用 7B 级轻量模型量化（Q4），RK3588 16GB 内存可承载；必要时云端 API fallback |
| RKNN 模型转换兼容性 | 中 | ONNX → RKNN 转换存在算子不支持风险；提前测试 YOLO/表情模型，必要时回退 ONNX Runtime CPU 推理 |
| 声音克隆效果不理想 | 中 | 降低预期目标（先做 TTS 音色切换，再追求极致克隆），使用成熟的 GPT-SoVITS 方案 |
| 步态预测需要长期数据 | 低 | 展示阶段使用"模拟趋势数据"演示，论文中说明需要 30 天以上实际数据 |
| 萤石设备接口不稳定 | 中 | 同时预留 RTSP 流接入方案，做兼容层 |
| 认知评估准确度 | 中 | 明确定位为"初筛工具"而非"诊断工具"，需在说明中注明 |
