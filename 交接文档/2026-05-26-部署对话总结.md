### 阶段 2 — 获取交叉编译工具链（60 分钟，仅一次）

需要在 **WSL2 Ubuntu** 中执行：

```bash
sudo apt install -y build-essential cmake git
cd ~ && git clone https://github.com/milkv-duo/duo-buildroot-sdk.git
cd duo-buildroot-sdk && ./build.sh milkv-duos-sd
echo "export MILKV_SDK=$HOME/duo-buildroot-sdk" >> ~/.bashrc
```

### 阶段 3 — 烧录系统 + 启动 Duo S（10 分钟）

- 用 **Rufus** 将 `duo-buildroot-sdk/out/milkv-duos-sd/images/milkv-duos-sd.img` 写入 microSD
- 插卡、Type-C 数据线连接电脑
- 安装 RNDIS 驱动
- SSH 连接：`ssh root@192.168.42.1`（密码 `milkv`）

### 阶段 4 — 交叉编译（5 分钟）

在 WSL2 中交叉编译：

```bash
cd /mnt/d/Users/wangxianxiu/.openclaw/workspace/huling_model/deploy/duos
mkdir build-riscv && cd build-riscv
cmake .. -DCMAKE_TOOLCHAIN_FILE=../toolchain-riscv.cmake
make -j$(nproc)
```

**产物：** `huling_demo`、`huling_test`、`huling_server`、`libhuling.a`

### 阶段 5 — 传文件到 Duo S（2 分钟）

```bash
scp huling_demo huling_test huling_server root@192.168.42.1:/root/
```
