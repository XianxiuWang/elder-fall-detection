## 四、踩过的坑（💀 别再踩）

### 新踩的（7/23）

**坑 1: mediapipe 0.10.35 砍掉了 `solutions` 模块**
- **症状**: `AttributeError: module 'mediapipe' has no attribute 'solutions'`
- **根因**: 0.10.35 只保留了新 Tasks API（`mediapipe.tasks.vision.PoseLandmarker`），旧 `mp.solutions.pose` API 被移除
- **解决**: **装 mediapipe==0.10.14**，不要用最新版！
  ```cmd
  pip install mediapipe==0.10.14 -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```
- **教训**: 项目所有依赖锁定版本号，mediapipe 一定用 0.10.14

**坑 2: model_complexity=2 要下载 heavy 模型，Google 被墙**
- **症状**: `Downloading model to ... pose_landmark_heavy.tflite` 然后卡住或 SSL 错误
- **根因**: model_complexity=2 触发 `_download_oss_pose_landmark_model()` 去 Google Storage 下载
- **解决**: 用 `model_complexity=1`（轻量模型已内置缓存，精度足够）
- **教训**: 别用 model_complexity=2，除非翻墙

**坑 3: 每 3 帧推理的跳帧逻辑导致骨骼闪烁**
- **症状**: 骨骼在画面中一闪一闪，看起来像在抽搐
- **根因**: `frame_idx % 3 != 0` 跳过推理但也跳过了骨骼绘制，中间 2 帧完全没有骨骼
- **解决**: 中间帧用 `prev_lm` 手动绘制（连线 + 圆点），视觉上完全平滑
- **教训**: 跳帧省算力时，**显示层不能跳**——用上一帧数据填充中间帧

**坑 4: `e2e_fall_monitor.py` 里 `gait_analyzer.update(lm)` 参数类型不匹配**
- **症状**: `TypeError: only length-1 arrays can be converted to Python scalars`
- **根因**: `update()` 第一参数期望 1D 特征向量，但传了 (33,4) 的原始关键点数组
- **解决**: 改为 `gait_analyzer.update(features=feat_vec, landmarks=lm, prev_landmarks=prev_lm)`
- **教训**: 调函数前看清参数签名，不要省略参数名

### 之前已记录的坑（仍然有效）

- **`sse` 不是 `ssv`**：SenseVoice 环境叫 `sse`（Python 3.10.20），不是 `ssv`
- **conda 关梯子**：conda + VPN/代理 = SSL 爆炸
- **PowerShell 不支持 `&&`**：用 `cmd /c` 或 `;` 代替
- **Joshua-Riek v2.4.0 不支持 Orange Pi 5 Pro**：必须用 v2.3.2
- **萤石 RTSP 端口是 554**，不是 App 里显示的 8000
