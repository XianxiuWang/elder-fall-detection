# HANDOFF_2026-07-31 — 多人检测功能实现

## 1. 需求

用户明确要求：
1. **多人关键点检测**：视频中出现两个人时，**两人都要有关键点检测**，不能只有一个人有
2. **多人任一跌倒预警**：只要检测到**任意一个人有跌倒倾向**，就发预警/警告

## 2. 完成了什么

### 2.1 新增 `src/multi_person.py` v1.0 ✅

YOLOv8n + IoU 行人跟踪 + 逐人 MediaPipe Pose 模块：

- **YOLOv8n 行人检测**：class=0 (person)，conf≥0.4，640x640 输入
- **IoU 跟踪**：贪心匹配，MIN_IOU=0.40，最多跟踪 6 人，丢失 15 帧后移除
- **逐人 MediaPipe Pose**：每人在 bbox 扩展 10% 的区域 crop 后独立推理，关键点映射回全帧 [0,1] 坐标
- **每人颜色分配**：6 种颜色循环

关键方法：
```python
tracker = PersonTracker()
persons = tracker.update(frame)  # → List[PersonResult]
# PersonResult: person_id, bbox, landmarks(33,4), has_landmarks, mediapipe_ms
```

### 2.2 修改 `e2e_fall_monitor.py` → v6.0 ✅

主要改动：
1. **新增 `--multi` / `--multi-person` 参数**：启用多人模式
2. **`PersonState` 类**：封装每人的独立检测器状态（ML6ClassDetector、FallPredictor、FallEarlyWarning、MotionSpatialAnalyzer、ProcessFallDetector、GaitTrendAnalyzer、SedentaryDetector、MedicationReminder）
3. **延迟初始化**：检测器在首次出现时才创建，节省资源
4. **`_process_person()`**：对单人跑完整管线 → 返回结果字典
5. **`process_frame()` 多人分支**：
   - YOLO 检测所有人 → 逐人处理
   - 每人画独立色骨架 + bbox + 状态标签
   - 右上角多人信息面板
   - **任一人物触发→全局告警**（顶部红色横幅 + 底部摘要栏）
6. **单人模式完全保持** (`--single` 或不传参)

## 3. 技术决策

| 决策 | 理由 |
|------|------|
| YOLOv8n 而非 YOLOv11 | 轻量(3.2M参数)，适合边缘部署，已充分验证 |
| crop+MediaPipe 而非全帧多人 | MediaPipe Pose Python API 仅输出单人；crop 后逐个推理是标准方案 |
| 每人独立检测器实例 | ProcessFallDetector/GaitTrend/ML6 都有状态机，不能共享 |
| 检测器延迟创建 | 多数帧只有1-2人，避免浪费 |
| 任意一人触发→全局告警 | 满足用户需求："只要一个人有倾向就发警告" |
| IoU 最小阈值 0.40 | 比标准 0.50 稍低，适应快速移动场景 |
