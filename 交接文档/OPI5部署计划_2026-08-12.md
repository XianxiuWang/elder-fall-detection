### 3.2 萤石 C6c RTSP 对接（主力方案，需要代码改造）

**⚠️ 当前 `cv_client.py` 只支持 `cv2.VideoCapture(int)`，RTSP 地址尚未支持。**

**步骤 3.2.1：配置萤石 C6c RTSP**
1. 下载萤石云 App → 添加设备 → 扫描 C6c 底部二维码
2. 进入设备设置 → 局域网服务 → 开启 RTSP
3. 获取 RTSP 地址，格式：
   ```
   rtsp://admin:设备验证码@192.168.x.x:554/h264/ch1/main/av_stream
   ```
   - **设备验证码**：设备底部标签上的 6 位大写字母
   - 记下 RTSP 地址，后续配置用

**步骤 3.2.2：代码改造 — 支持 RTSP 源**

在 `cv_client.py` 中增加 RTSP 源支持。需要改的文件：

**① 修改摄像头打开逻辑**（约 200 行附近）：
```python
# 原代码（约第 202 行）:
cap = cv2.VideoCapture(camera_id)

# 改为:
def open_camera(source):
    """打开摄像头，支持整数 ID 和 RTSP URL"""
    if isinstance(source, int) or source.isdigit():
        cap = cv2.VideoCapture(int(source))
    else:
        # RTSP / 文件路径
        cap = cv2.VideoCapture(source)
        # RTSP 优化：使用 TCP 传输（降低丢帧）
        if source.startswith('rtsp://'):
            os.environ["OPENCV_FFMPEG_CAPTURE_OPTIONS"] = "rtsp_transport;tcp"
    cap.set(cv2.CAP_PROP_FRAME_WIDTH, 640)
    cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 480)
    # 缓冲区设为 1（减少延迟）
    cap.set(cv2.CAP_PROP_BUFFERSIZE, 1)
    return cap
```

**② 修改命令行参数**（约 467 行）：
```python

    help="摄像头ID(整数) 或 RTSP地址(如 rtsp://...) 或视频文件路径")
```

## 阶段 5：性能调优（逐级降载）

调优策略：先跑起来，再优化。

| 参数 | 默认值 | 调优方案 | 位置 |
|------|--------|---------|------|
| SKIP_FRAMES | 3 | 帧率不够 → 调大到 4 或 5 | `fall_inference.py` 顶部 |
| MODEL_COMPLEXITY | 1 | 帧率不够 → 降到 0（牺牲一点精度） | `fall_inference.py` 顶部 |

## 附录 A：踩坑预案

### A1: MediaPipe 在 ARM64 上安装失败
```bash
# 方案 1: 指定版本
pip install mediapipe==0.10.14

# 方案 2: piwheels 预编译
pip install mediapipe --index-url https://www.piwheels.org/simple

# 方案 3: 检查 Python 版本
python3 --version
# Python 3.12+ 需要 mediapipe >= 0.10.18
pip install mediapipe==0.10.18

# 方案 4: 如果还是失败，考虑降级 Python
# 用 conda 或 pyenv 安装 Python 3.10 专门跑这个项目
```

### A2: 萤石 C6c RTSP 连不上
- 确认设备和 OPI5 在同一 WiFi 下
- 确认"设备验证码"是大写字母，标签上有
- 先用 VLC 测试：打开网络串流 → 输入 RTSP 地址 → 能否看到画面
- RTSP 失败就用 USB 摄像头先顶上（效果一样，只是答辩不加分）

### A3: 风扇不转
```bash
# 手动设置 PWM
echo 255 | sudo tee /sys/class/pwm/pwmchip0/pwm0/duty_cycle
# 或
sudo apt install -y fancontrol
sudo pwmconfig   # 自动配置风扇
```

### A4: OPI5 4GB 内存不够
- 关掉不需要的服务：`sudo systemctl disable bluetooth`
- 减少 `POSE_CHUNK` 到 100
- 如果需要同时跑 DeepFace（王权瑶的模块）→ 分时运行，或人脸跑在另一台设备

### A5: 系统代理干扰（PC 端）
- 每次新 CMD 先清代理：
  ```cmd
  set HTTP_PROXY= && set HTTPS_PROXY= && set http_proxy= && set https_proxy=
  ```
- OPI5 上通常没有代理问题
