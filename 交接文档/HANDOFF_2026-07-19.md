## 六、踩过的坑（💀 别再踩）

### 今天新踩的

**坑 1: Joshua-Riek v2.4.0 不支持 Orange Pi 5 Pro**
- **坑**: 最新版（Ubuntu 24.10）的 Release Notes 只列出了 Orange Pi 5 / 5B / 5+，没有 5 Pro
- **解决**: 用 v2.3.2（Ubuntu 24.04），是最后一个支持 5 Pro 的版本
- **教训**: **下载镜像前一定要看 Release Notes 的支持列表，别默认最新版支持你的板子**

**坑 2: 萤石 App 打开 RTSP 后不显示 RTSP 地址**
- **坑**: 教程说"App 会给你一行地址"，实际上新固件可能不显示
- **解决**: 手动拼 `rtsp://admin:验证码@IP:554/h264/ch1/main/av_stream`
- **需要三样东西**: IP（App 设备信息页）+ 验证码（摄像头底部贴纸）+ 固定格式

**坑 3: 萤石 App 显示的端口不是 RTSP 端口**
- **坑**: App 设备信息显示 `192.168.1.100:8000`，但 8000 是 App 管理端口，不是 RTSP 端口
- **解决**: RTSP 端口固定是 554

**坑 4: GitHub Release 页面是 JS 渲染，无法用 web_fetch 抓取文件列表**
- **影响**: 无法自动获取下载链接，需要手动推断 URL 或用浏览器打开
- **教训**: `web_fetch` 对 JS 渲染页面无能为力，这种情况直接让用户用浏览器

### 之前的坑（仍有效）

- **Python/PowerShell 编码坑**: 不要在 PowerShell 用 python -c 跑带中文/emoji 的代码，写成 .py 文件再跑
- **国内平台反爬**: 7 个平台全有反爬，手动存 HTML 比写爬虫快 10 倍
- **系统代理**: 如果 pip/conda 报 SSL 错误，先把 HTTP_PROXY 清了
- **Conda 国内镜像**: 不稳定，默认源反而更可靠
- **PowerShell 的 `&&`**: 不支持！用 `;` 或写 .bat

**资料 2**: FMCW 雷达论文解读 — "为什么雷达只看速度还不够？"

| 核心问题 | 核心解法 |
|------|------|
| 只看速度峰值 → 把翻身/起身误判成跌倒 | 加距离维度：**Centroid Range**（距离质心）+ **Range Width**（距离宽度） |
| 跌倒 vs 日常动作速度可能一样 | 跌倒 = 全身大范围位移；日常 = 局部小范围 |
| 召回率 0.573→0.718（SVM）, 0.609→0.745（LDA） | 准确率只涨 1-2%，但**真跌倒不漏报**大幅提升 |

**一句话**: 跌倒检测不能只看"动得快不快"，还要看"人在空间里怎么移动"。

### 🆕 基于两份资料，写了三个新模块

#### `gait_trend.py` — 步态趋势分析层（滑动窗口+风险评分）

五级架构：
```
摄像头帧 → MediaPipe 33关键点 → GaitMetricExtractor → GaitWindow(7天) → TrendAnalyzer → TrendReport
```

| 类 | 功能 |
|------|------|
| `GaitSample` | 单帧步态指标（步长/步速/摇晃角/平衡/膝角/质心高） |
| `GaitMetricExtractor` | 从 huling 特征向量提取步态指标 |
| `GaitWindow` | 7天滑动窗口，支持 JSON 保存/恢复 |
| `TrendAnalyzer` | 三维评分：基线偏移(30%) + 趋势斜率(40%) + 不稳定性(30%) |
| `GaitTrendAnalyzer` | 全家桶封装，一行 `update()` 搞定 |

风险分 0-100：🟢 绿色 = 正常 / 🟡 黄色 = 关注 / 🟠 橙色 = 预警 / 🔴 红色 = 警报

#### `motion_spatial.py` — 空间运动分析（FMCW 雷达论文灵感改造）

雷达特征 → 2D 摄像头改造：

| 雷达特征 | 摄像头改造 | 含义 |
|------|------|------|
| Centroid Range | `motion_centroid_disp` | 运动中心帧间位移 |
| Range Width | `motion_spread_width` | 运动关键点空间跨度 |
| — | `motion_spread_active` | 运动中关键点比例（0-1） |
| — | `torso_disp_ratio` | 躯干位移占比（区分局部 vs 全身） |
| — | `upper_lower_ratio` | 上半身/下半身位移比 |

输出 6 维特征，直接可喂分类器。

**测试结果**: 挥手 0.25 vs 跌倒 0.88，区分比 **3.5x** ✅

#### `process_fall_detector.py` — 过程级跌倒检测（瞳芯颐护灵感）

**核心改革**: 不单帧判断 → 看 N 帧序列的整体过程

三阶段状态机：NORMAL → COLLECTING → ANALYZING

| 分析维度 | 权重 | 逻辑 |
|------|:--:|------|
| 速度轨迹 | 25% | 先升后降 = 撞击后静止 |
| **高度轨迹** | **30%** | 持续下降+不反弹 = 跌倒（不是弯腰弹回） |
| 躯干姿态 | 20% | 垂直→水平 + 单调变化 |
| 运动扩散 | 10% | 全身多处同时动 |
| 后段静止 | 15% | 撞后真的不动了 |
