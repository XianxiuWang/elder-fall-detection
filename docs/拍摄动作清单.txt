  跌倒动作详解 (按键 1-4):

    [正向跌倒] 面朝镜头站立 → 自然前倾失去平衡 → 双手伸出撑地缓冲
              → 最终趴在垫子上 → 保持 2 秒

    [侧向跌倒] 侧对镜头站立 → 向左(或右)侧面倾倒 → 手臂撑地
              → 身体侧面着地 → 保持 2 秒

    [后仰跌倒] 背对镜头站立 → 向后失去平衡 → 臀部先着地 → 背部着地
              → 保持 2 秒

    [滑倒]     正常行走中 → 模拟踩到湿滑地面 → 脚向前滑出
              → 身体后仰 → 臀部着地 → 保持 2 秒

================================================================================

  日常动作详解 (按键 5-9):

    [正常行走] 在镜头前来回走 2-3 趟 → 正常步速 + 较慢 + 较快

    [弯腰捡物] 站立 → 弯腰捡地上物品 → 停顿 1 秒 → 正常站起

    [坐下起立] 站在椅子前方 → 坐下 → 坐 2-3 秒 → 起立

    [蹲下起立] 站立 → 蹲下 → 保持蹲姿 2 秒 → 起立

    [缓慢躺下] 站立 → 慢慢蹲下 → 侧身 → 缓慢躺到垫子上 → 保持 2 秒

================================================================================

  ⚠️ 安全提醒:
    1. 必须有第二人在旁边保护
    2. 垫子要足够厚
    3. 跌倒时用手臂缓冲, 不要直接摔
    4. 感觉不适立刻停止
    5. 不要硬地板练习
