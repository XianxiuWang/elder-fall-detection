# Orange Pi 5 Pro 刷机教程

## 你需要准备

| 东西 | 要求 |
|------|------|
| TF 卡（MicroSD） | ≥16GB，Class 10 或 U3（读写快的那种） |
| 读卡器 | TF 转 USB |
| 电源适配器 | Type-C，**5V/4A**（很重要！别用手机充电器） |
| 网线（建议） | 第一次用网线连路由器最省事 |

---

## 第一步：下载镜像

镜像文件：`E:\老人跌倒\orangepi5pro-ubuntu-24.04-server-v2.3.2.img.xz`

下载地址（如果本地没有）：
```
https://github.com/Joshua-Riek/ubuntu-rockchip/releases/download/v2.3.2/ubuntu-24.04-preinstalled-server-arm64-orangepi-5-pro.img.xz
```

镜像信息：
- 系统：Ubuntu 24.04 LTS
- 类型：Server 版（无桌面，省内存）
- 内核：6.1（支持 NPU）
- 大小：约 1.5GB 压缩包

---

## 第二步：写入 TF 卡

### 下载 balenaEtcher
```
https://www.balena.io/etcher/
```
装好后打开。

### 写入步骤
```
1. 打开 balenaEtcher
2. 点 "Flash from file" → 选 .img.xz 文件（不用解压，Etcher 自动处理）
3. 点 "Select target" → 选你的 TF 卡
4. 点 "Flash!" → 等 5-10 分钟
5. 完成后弹出 TF 卡
```

> ⚠️ 写入会清空 TF 卡，备份好里面东西

---

## 第三步：开机

```
1. TF 卡插入 Orange Pi 5 Pro 卡槽
2. 插网线到路由器（推荐，WiFi 也可以）
3. 插 Type-C 电源
4. 红灯亮起 → 绿灯闪烁 → 等 1-2 分钟
```

---

## 第四步：连接

### 方式一：SSH（推荐）

在路由器后台找到 Orange Pi 5 Pro 的 IP 地址，然后：

```bash
ssh ubuntu@你的IP
```

### 默认账号密码
```
用户名: ubuntu
密码: ubuntu
```
首次登录会**强制你改密码**。

### 方式二：接显示器+键盘

插 HDMI 接显示器，USB 接键盘。看到登录界面后输入 `ubuntu` / `ubuntu`。

---

## 第五步：进系统后第一件事

```bash
# 1. 更新系统
sudo apt update && sudo apt upgrade -y

# 2. 验证 NPU（显示 rknpu 就是正常）
sudo dmesg | grep -i rknpu

# 3. 装 Python 和 pip
sudo apt install python3 python3-pip python3-venv -y
```

---

## 刷机完成标志

- SSH 能连上
- `dmesg | grep rknpu` 有输出
- `python3 --version` 正常

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 开机灯不亮 | 电源功率不够，换 5V/4A 适配器 |
| SSH 连不上 | 进路由器后台确认 IP，或插显示器看 |
| TF 卡写不进 | 换一个读卡器试试 |
| 反复重启 | 电源问题（最常见），或 TF 卡兼容性 |
