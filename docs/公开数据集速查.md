## 1. SDUFall ★★★ 首推

| 项目 | 详情 |
|------|------|
| 来源 | 山东大学 (Shandong University) |
| 官网 | http://www.sucro.org/ 或搜 "SDUFall dataset" |
| 规模 | **20 人 × 6 类动作 × 10 次 = 1200 段** |
| 传感器 | Kinect v2 (RGB + Depth + Skeleton) |
| 动作 | 前摔、后摔、左摔、右摔、蹲下、坐下 |
| 帧率 | 30fps |
| 分辨率 | 640×480 |
| 关键点 | 自带 Kinect skeleton (25 关节点), 不用跑 MediaPipe! |

**为什么首推**: 已经有骨骼关节点数据，直接转成 33 点 MediaPipe 格式就能喂模型。1200 段混进去训练，泛化能力质变。

### 关键点适配方案

SDUFall 自带 25 个 Kinect 关节点，映射到 MediaPipe 33 点：
```
Kinect (25)      →  MediaPipe (33)
SPINE_BASE       →  0 (nose)           [用躯干近似]
SPINE_MID        →  12 (left_shoulder) [近似]
SPINE_SHOULDER   →  11 (right_shoulder)[近似]
NECK             →  0 (nose)
HEAD             →  0 (nose)
SHOULDER_LEFT    →  11
ELBOW_LEFT       →  13
WRIST_LEFT       →  15
HAND_LEFT        →  19
SHOULDER_RIGHT   →  12
ELBOW_RIGHT      →  14
WRIST_RIGHT      →  16
HAND_RIGHT       →  20
HIP_LEFT         →  23
KNEE_LEFT        →  25
ANKLE_LEFT       →  27
FOOT_LEFT        →  31
HIP_RIGHT        →  24
KNEE_RIGHT       →  26
ANKLE_RIGHT      →  28
FOOT_RIGHT       →  32
```

写个转换脚本 20 分钟搞定。

## 2. Le2i Fall (Télécom SudParis / UBFC)

| 项目 | 详情 |
|------|------|
| 官网 | http://le2i.cnrs.fr/Fall-detection-dataset |
| 规模 | **191 段视频** (多种室内场景) |
| 传感器 | 普通 RGB 摄像头 |
| 分辨率 | 320×240 到 1080p 不等 |
| 场景 | 办公室、咖啡厅、客厅、卧室 |
| 多样性 | 含老年人演员、不同光照、遮挡 |

**优点**: 四种真实室内场景，与你的客厅/卧室监控最接近。
**缺点**: 需自己跑 MediaPipe 提关键点（我们有 urfd_loader.py 可以复用）。

## 3. Multiple Cameras Fall (URF MediaPipe 版)

| 项目 | 详情 |
|------|------|
| 官网 | http://www.iro.umontreal.ca/~labimage/Dataset/ |
| 规模 | **192 段** (24 场景 × 8 视角) |
| 传感器 | 8 台普通 RGB 摄像头 |
| 亮点 | 同一次摔跤 8 个角度同时录 → 视角泛化训练 |
| 标签 | 与 URFD 同类, 帧级标注 |

**用途**: 如果不满足 URFD 的 70 段，这个是同一系列的高品质补充。

---

## 4. UP-Fall Detection

| 项目 | 详情 |
|------|------|
| 官网 | https://sites.google.com/up.edu.mx/up-falldetection/ |
| 规模 | 17 人 × 2 次测验 × 11 类动作 = 374 段 |
| 传感器 | 5 个摄像头 + 可穿戴 + 环境传感器 |
| 动作 | 前摔、后摔、侧摔、跳跃、摇晃椅子等 11 类 |

**优点**: 跨模态（多传感器）, 摔倒类型更丰富。
**缺点**: 配置复杂, 需处理 5 个摄像头的时间同步。

## 行动建议

```
优先级: SDUFall > Le2i > Multiple Cameras Fall > UP-Fall
```

**本周能搞定的**:
1. 下载 SDUFall（到国内镜像如 Kaggle 或百度网盘更快）
2. 写 25→33 关键点映射 + 格式转换脚本
3. 转换后 .npz 与 URFD 格式统一 → 直接丢进 data/urfd_features/
4. 混合重训 → 1200+70=1270 段

下载地址可能需要翻墙或从国内镜像找（百度网盘/阿里云盘有人转过）。搜关键词:
- "SDUFall dataset 下载"
- "SDUFall Kinect skeleton"
- "Kaggle SDUFall"
- "SDUFall 数据集 百度网盘"

## 备选渠道（官网挂了的话）

### 渠道 1: Kaggle
https://www.kaggle.com/ 搜 "SDUFall" — 有人传了完整数据集 + 预处理后的关节点版本。

### 渠道 2: GitHub 预处理版
https://github.com/ 搜 "SDUFall skeleton" 或 "SDUFall pose estimation" — 
有人已经跑完 OpenPose/AlphaPose 把骨骼提取好, 比原始 Kinect 关节点更接近 MediaPipe 33 点。

### 渠道 3: IEEE DataPort / Mendeley Data
搜 "SDUFall IEEE DataPort" 或 "SDUFall Mendeley" — 学术数据镜像站。

### 渠道 4: 百度网盘/阿里云盘
中文搜 "SDUFall 数据集" — 国内研究团队转过, 下载快。

### 渠道 5: Le2i 官网（替代 SDUFall）
http://le2i.cnrs.fr/Fall-detection-dataset
→ 191 段, 这个站比较稳定, 如果 SDUFall 实在下不到先拿这个用。
