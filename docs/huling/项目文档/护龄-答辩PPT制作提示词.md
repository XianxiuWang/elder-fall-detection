### Slide 8 | 关键技术三：RandomForest + m2cgen 零依赖部署

```
【标题】3MB 纯 C 代码，零运行时依赖 —— RandomForest + m2cgen
【内容】
  为什么选 RandomForest？
    · 100 棵树，每棵 max_depth=12，Bagging + 随机特征
    · 精度 ≈ 90%（与小型 CNN 相当）
    · 推理 <2ms/帧（RISC-V 1GHz）
    · 可解释性强

  m2cgen 一键转换：
    scikit-learn 模型 → 84,000 行纯 C 代码
    → gcc/CMake 交叉编译 → ARM/RISC-V 二进制 → 板载运行

  对比：
    vs TF Lite Micro: 不需 20MB+ 运行时
    vs ONNX Runtime: 不需复杂交叉编译
    vs 深度学习: 不需 GPU/TPU
【视觉】
  - 左边：100棵树随机森林示意（多棵树 → 投票 → 分类）
  - 右边：m2cgen 转换流程图（Python模型 → C代码 → 编译 → 板卡）
  - 底部：大字标语"训练在 Python，运行在 RISC-V"
【答辩话术】"最酷的部分来了——我们用 m2cgen 把训练好的 Python 模型，一键变成 8万多行纯 C 代码。没有 TensorFlow、没有 PyTorch、没有任何运行时框架，一个 gcc 直接编译，就能在 35 块钱的 RISC-V 芯片上跑。"
```
